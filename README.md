# Фактограф — выпуск №48

Демонстрационный редакционный сайт в стиле новостного издания: «ТОП-15 интереснейших малоизвестных фактов» о науке, природе и географии.

## Что внутри

- 15 фактов: 5 научных, 5 о природе, 5 географических, у каждого — числовая деталь и раскрывающийся блок «Деталь».
- Главный факт выпуска — Венера, где сутки длиннее года.
- Собственные SVG-иллюстрации без внешних изображений: сайт работает без фотографий и не зависит от стоков.
- Фильтры по рубрикам, живой поиск, сохранение фактов в `localStorage`, копирование ссылки на факт или выпуск.
- Демонстрационная форма дайджеста с валидацией (письма не отправляются).
- Мобильное меню, индикатор прогресса чтения, адаптив от 320 px, поддержка `prefers-reduced-motion`.

## Запуск

Откройте `index.html` в браузере. Для проверки `localStorage` и буфера обмена удобнее локальный сервер из папки проекта:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:5173/`.

## Технические заметки

- Без сборки и зависимостей: один HTML-файл, один CSS, один JS.
- Шрифты Lora и Inter подключены с Google Fonts; при отсутствии сети используются системные Georgia и Segoe UI.
- Сохранённые факты хранятся в ключе `factograf.saved.v1`.
- Ссылки на факты имеют вид `#fact-01` … `#fact-15`; при открытии такой ссылки фильтры сбрасываются автоматически.
- Форма дайджеста и счётчики — демонстрационные. Сайт не является СМИ.
